# CP1251Converter

A small macOS AppKit app that converts a dragged text file from Windows-1251 / CP1251 to UTF-8.

## Usage

1. Open `CP1251Converter.xcodeproj` in Xcode.
2. Run the `CP1251Converter` scheme.
3. Drag a text file into the drop area.
4. Click `Convert`.

The app overwrites the selected file with its UTF-8 version.
